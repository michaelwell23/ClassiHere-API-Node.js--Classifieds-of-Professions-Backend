# ClassiHere API

Backend oficial da plataforma ClassiHere.

## Tecnologias

- Node.js
- Express
- PostgreSQL
- Sequelize
- Docker

## Instalação

```bash
npm install
```

## Ambiente

Copie:

```bash
cp .env.example .env
```

## Executar

```bash
npm run dev
```

## Estrutura

Arquitetura modular baseada em domínio.
